What Is Concurrency Control?

In a multi‑user database, concurrency control ensures that simultaneous transactions do not corrupt data. Common mechanisms include:

  • Locking — a transaction acquires a lock on a row or table, blocking others until it finishes.
  • UNIQUE constraints — the database rejects a second INSERT/UPDATE that would create a duplicate value in a uniquely‑constrained column combination.
  • Serializable isolation — transactions are ordered so the net effect is the same as running them one after another.
