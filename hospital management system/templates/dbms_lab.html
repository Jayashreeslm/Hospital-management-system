This page demonstrates DDL (Data Definition Language) and DML (Data Manipulation Language) operations on the hospital management database. Each demo runs a real SQL statement against a temporary demonstration table and displays the result below.

DDL — Data Definition Language

CREATE TABLE

CREATE TABLE IF NOT EXISTS Demo_Log (
    Log_ID    INTEGER PRIMARY KEY AUTOINCREMENT,
    Action    TEXT    NOT NULL,
    Detail    TEXT,
    Created   DATETIME DEFAULT CURRENT_TIMESTAMP
);

Creates a temporary Demo_Log table used by subsequent demonstrations. The table stores an auto‑incrementing ID, an action label, a detail string, and a timestamp.

ALTER TABLE

ALTER TABLE Demo_Log ADD COLUMN Status TEXT DEFAULT 'active';

Adds a new Status column to the Demo_Log table with a default value of 'active'. This demonstrates how schemas can evolve without recreating the table.

DML — Data Manipulation Language

INSERT

INSERT INTO Demo_Log (Action, Detail)
VALUES ('INSERT_TEST', 'Row inserted via DBMS Lab demo');

Inserts a new row into Demo_Log. The Log_ID and Created columns are populated automatically by the database engine.

SELECT

SELECT * FROM Demo_Log ORDER BY Log_ID DESC;

Retrieves all rows from Demo_Log, ordered by ID descending so the newest entries appear first.

JOIN

SELECT a.Appointment_ID, p.Name AS Patient, d.Name AS Doctor, a.DateTime
FROM Appointment a
INNER JOIN Patient p ON a.Patient_ID = p.Patient_ID
INNER JOIN Doctor d  ON a.Doctor_ID  = d.Doctor_ID
ORDER BY a.DateTime DESC
LIMIT 10;

Joins the Appointment, Patient, and Doctor tables to produce a human‑readable list of recent appointments.

UPDATE

UPDATE Demo_Log
SET Detail = 'Updated by DBMS Lab demo', Status = 'modified'
WHERE Action = 'INSERT_TEST';

Updates all rows whose Action is 'INSERT_TEST', changing the detail text and setting the status to 'modified'.

DELETE

DELETE FROM Demo_Log WHERE Action = 'INSERT_TEST';

Removes all rows matching the WHERE condition. This is irreversible unless wrapped in a transaction with a rollback.

Aggregate (GROUP BY)

SELECT d.Name AS Doctor, d.Specialization,
       COUNT(a.Appointment_ID) AS Total_Appointments
FROM Doctor d
LEFT JOIN Appointment a ON d.Doctor_ID = a.Doctor_ID
GROUP BY d.Doctor_ID
ORDER BY Total_Appointments DESC;

Groups appointments by doctor and counts them, demonstrating the GROUP BY clause with an aggregate function (COUNT).

Subquery

SELECT Name, Specialization
FROM Doctor
WHERE Doctor_ID IN (
    SELECT Doctor_ID
    FROM Appointment
    GROUP BY Doctor_ID
    HAVING COUNT(*) >= 1
);

Uses a subquery to find doctors who have at least one appointment. The inner query identifies qualifying Doctor_IDs, and the outer query fetches their details.
